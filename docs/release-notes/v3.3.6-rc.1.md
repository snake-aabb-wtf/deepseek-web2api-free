# v3.3.6-rc.1 — WebUI 启动依赖安装修复（预发布）

> 2026-10-03 · release candidate

## 修复

- `start.bat` 委托独立构建脚本处理 WebUI 依赖和构建。
- 构建前检查 `tsc` 与 `vite` 是否存在；依赖安装失败或工具仍缺失时立即报错退出，避免残缺的 `node_modules` 导致后续启动报错。
- 有 `package-lock.json` 时使用 `npm ci`，并在安装失败时提示检查 npm registry 或代理连接。
- GitHub Release 工作流将带预发布后缀的标签（例如 `v3.3.6-rc.1`）创建为预发布版本。

## 验证说明

- 已检查批处理文件的差异格式。
- WebUI 构建未运行：当前环境 npm registry 代理不可达，依赖安装失败；本版本修复了失败后的错误处理路径。
