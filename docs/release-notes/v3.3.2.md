# v3.3.2 — admin dashboard history chart fix

> 2026-09-05 · bugfix release

## Highlights

- **Merged PR #14 (stats history fix)** — the WebUI dashboard "Request Trend" chart no longer stays empty forever. Big thanks to **[@Zhangkc](https://github.com/Zhangkc)** for the clean root-cause analysis, the minimal fix, and production before/after evidence:
  - **Root cause**: `stats_history.StatsHistory.snapshot()` read `stats.avg_latency_ms`, an attribute that does not exist on `admin.StatsSnapshot` (which only tracks `total_latency_ms`; the `/admin/api/stats` endpoint computes the average itself). Every snapshot therefore raised `AttributeError`, and the sampler thread swallowed it silently (`except Exception: pass`) — so `/admin/api/history` returned `points: []` from process startup on, no matter how long the process ran.
  - **Fix**: `snapshot()` now derives the average exactly like the `/admin/api/stats` endpoint does: `total_latency_ms / total_requests`, guarded to `0.0` when there are no requests yet.

## Tests

- New `tests/test_stats_history.py` (4 cases):
  - snapshot records the expected point values;
  - zero requests → no division by zero, `avg_latency_ms = 0.0`;
  - **strict-object regression test** — a `__getattr__` that raises `AssertionError` on unknown attributes ensures `snapshot()` only ever touches fields that really exist on `StatsSnapshot` (the exact failure mode that caused this bug);
  - `max_points` truncation keeps the buffer bounded.

## Verification

- Local run: `86 passed`.
- Review reproduced the pre-fix `AttributeError: 'StatsSnapshot' object has no attribute 'avg_latency_ms'` against main's code, then verified the patched `snapshot()` against a real `admin.StatsSnapshot` (correct values + zero-request boundary).
- Production report from the PR: `/admin/api/history` went from `points: []` (30+ hours uptime, 951 requests) to normal point accumulation after applying the patch, and the chart renders again.

## Notes

- No API, config, or env changes. Existing deployments only need to pull and restart to pick up the fix.
