# v3.3.6-rc.3 — WebUI 客户端 API Key 管理（预发布）

> 2026-10-03 · release candidate

## 新增

- WebUI「设置」页支持为不同客户端生成多个 API Key、复制新 Key、查看 Key 前缀和创建时间，并单独撤销 Key。
- 完整 Key 仅在创建时返回一次；服务端在 `data/api_keys.sqlite3` 中只保存 SHA-256 哈希。
- 旧版 `.env` 中的 `API_KEYS` / `DEEPSEEK_API_KEY` 会在首次初始化 Key 数据库时导入一次，之后 API 鉴权由数据库管理。
- 管理接口返回的服务版本号更新为 `3.3.6-rc.3`。

## 修复与验证

- `start.bat` 启动时若不存在 `.env`，会从 `.env.example` 创建配置文件。
- 新增 API Key 存储、一次性导入、管理接口及 `/v1` 鉴权测试，并纳入 Python 3.10–3.12 CI 单测矩阵。
- 本地验证：108 项 pytest、smoke test 和 e2e 检查通过。
