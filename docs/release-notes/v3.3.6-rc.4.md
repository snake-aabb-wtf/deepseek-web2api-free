# v3.3.6-rc.4 — 账号池配置统一（预发布）

> 2026-10-03 · release candidate

## 变更

- 移除 `.env` 账号兜底加载；账号只通过 WebUI 账号池或 `data/accounts.json` 配置。
- 不再读取编号式和旧式 `DEEPSEEK_TOKEN`、`DEEPSEEK_COOKIES`、`DEEPSEEK_EMAIL` 配置，也移除了只服务于 env 账号兜底的逐账号代理配置。
- 空账号池不会再尝试环境变量凭证；启动日志提示在 WebUI 或 `data/accounts.json` 中添加账号。
- WebUI 移除 env 账号只读状态和来源统计；更新 `.env.example`、中英文 README 与维护文档。
- 管理接口返回的服务版本号更新为 `3.3.6-rc.4`。

## 验证

- 全套 pytest：103 项通过。
- WebUI：TypeScript 检查和 Vite 生产构建通过。
