# v4.2.0 — 管理面板支持英文

浏览器尚未保存语言偏好时，管理面板首次打开会显示英文。登录后，点击右上角的语言按钮即可选择 **中文** 或 **English**。浏览器会记住选择，刷新页面或下次打开时继续使用该语言。

## 界面与错误提示

- 登录页、概览、账号池、Playground、设置和 404 页面支持中英文。切换语言会同时更新页面标题和 HTML 语言标记。
- 切换时会保留当前页面状态。在 Playground 中，未发送的草稿、系统提示和开关设置都可继续使用。在设置页，刚生成且只展示一次的 API Key 仍可复制。
- 上游账号被静音时，错误提示会显示英文说明和中文摘要。Chat Completions 和 Anthropic Messages 的非流式请求遇到上游限流或空响应时，也会返回双语提示。

## 从旧版升级

更新源码后，如果已有 `webui-new/dist/`，需要重新构建前端才能看到语言菜单。在 `webui-new/` 中依次执行 `npm ci` 和 `npm run build`，然后重启服务并刷新管理面板。

Windows 用户也可用启动脚本完成这一步。在项目根目录打开命令提示符，执行 `set WEBUI_REBUILD=1`，再运行 `start.bat`。
